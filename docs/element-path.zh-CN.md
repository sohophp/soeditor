# 状态栏元素路径

元素路径由 `packages/ui/src/element-path.ts` 的独立只读组件实现，拥有自己的渲染调度和销毁过程。UI 层提供当前实例选区，字数统计不再负责读取或拼接路径。

- 所见即所得显示选区公共祖先到正文根之间的真实元素标签；单个选中图片包含 `img`。
- 识别 Shadow DOM 选区，不包含编辑器容器、状态栏、CodeMirror 行或内部 `div`。
- 分屏按当前活动编辑模式显示。Source 激活时隐藏 DOM 路径；本组件不将源码行 DOM 解释成 HTML 语法树，也不另行解析全文。
- 跨实例或移出正文的选区清空路径；整体替换内容后不会沿已断开的旧节点继续显示。
- 路径仅显示标签层级，不执行选择、修改正文或历史命令；不会写入保存的 HTML。

每帧最多读取一次，计算量随所选节点祖先深度增长，不随全文大小增长。计算不读取布局尺寸、不遍历全文、不调用 HTML 解析器；路径未变化时不重写 DOM。销毁取消待执行帧，关闭实例后不继续更新。

浏览器回归覆盖嵌套列表、图片、Source 分屏、多实例和内容替换。调度测试连续请求 1,000 次更新只读取一次，下一帧相同路径不重写文本，销毁后的待执行任务被取消。此检查验证调度机制，不等于任意设备的输入延迟保证。
