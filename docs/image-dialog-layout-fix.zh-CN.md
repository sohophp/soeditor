# CMS 图片属性窗口布局修复

2026-09-09 在 Winstar 后台联调中发现，图片属性的输入框设置 `width: 100%` 后，
默认 content-box 仍把 padding 和 border 加在宽度之外，导致两列控件相互贴近、
右侧控件超出字段范围。宿主页面还可能改变 legend 的浮动和控件字号。

`classic-editor.css` 在图片窗口范围内统一 border-box，重置 legend 浮动，
限制字段最小宽度，并统一正文边距、控件字体和现有主题变量。桌面保留两列，
窄屏保持单列，正文内部滚动，底部操作始终可用。

验证：编辑器及依赖包构建、图片窗口拖动／缩放与字段边界浏览器回归通过；
Winstar 本机链接源码，19 项集成测试及前端构建通过。已检查 1100×850 和
390×700 截图，未进行真实 Safari 或辅助技术人工认证。
