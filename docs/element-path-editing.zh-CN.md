# 可视元素路径与安全移除

点击正文后，底部元素路径展示原文章结构，例如 `h1 › ul › li`。
点击 `h1` 可选择整个标题；路径旁的「移除外层标签」仅删除 H1 外壳，
保留 UL、LI、链接、媒体、注释和文字。空容器有正文外的标签标记。
打开文章、查看路径和选择标签不会修改内容或产生撤销记录，不要求启用 Source。

## 三种操作

- 移除外层标签：删除标签及标签自身属性，不向子节点转移 ID 或样式。
- 切换段落：普通标题变成 P。选中外层标题且包含列表／表格时，保留这些
  结构，并把前后文字转成独立段落；直接选择 LI 则仅转换该列表项。
- 清除格式：移除选区格式，不删除标题、列表、媒体和链接结构。

允许移除 H1–H6、P、DIV、SPAN、BLOCKQUOTE 及常用内联格式标签。
列表、表格、链接、媒体、自定义对象、组件和不可编辑内容不能直接拆除。
只读或输入法组合期间禁用结构修改。点击正文退出区块选择；操作支持撤销／重做。

## 集成契约

`VisualEditingService.getElementPath()` 返回只读条目：`id`、`tagName`、
`selected`、`canUnwrap` 与可选 `unavailableReason`。
`element.select(id)` 只调整选择，`element.unwrap()` 修改当前明确选择的容器。
ID 属于当前实例和投影版本，不能跨实例或内容重设复用。
Classic 通过 UI 的 `readElementPath` 回调桥接能力；UI 不依赖具体编辑引擎。

辅助标记和范围轮廓均在文章 DOM 外。正文 HTML 是唯一持久化内容，
不得在加载或提交时全局修正既有非法结构，危险内容仍必须保持惰性。

## 验证

运行 WYSIWYG、Classic 元素路径及 Winstar 集成测试；分别验证 Chromium、
Firefox、WebKit 与窄屏。记录无法运行的环境，不把测试页当作已登录后台验收。
`scripts/measure-element-path.mjs <旧构建来源归档> <结果文件>` 比较
10／100／500 KiB 文档的启动、输入、路径、选择和拆除成本，并检查辅助 DOM 清理。
CMS 加载脚本即使预算失败也保存测量记录，预算失败仍以非零状态退出。
构建必须先完成编辑器依赖和 CMS 包，再构建 Winstar 并核验来源及产物校验值。
