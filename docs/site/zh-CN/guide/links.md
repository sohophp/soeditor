# 链接与 CMS 标记

通过链接对话框读取并修改当前链接，填写目标地址并确认。取消操作应保持原内容与选择。

HTML 注释、自定义元素、class 和配置的 CMS 占位符具有内容意义。保留不代表允许执行：事件属性、脚本和可执行嵌入必须在编辑区域保持惰性。

资源文件链接通过宿主资源选择器接入。保存时使用规范 HTML，不能把编辑器临时类名或选中状态写入数据库。
