# 文本与列表

选中文本后使用粗体、斜体和链接等行内工具；段落、标题、引用和列表作用于相应块。对齐与缩进通过命令完成，撤销恢复为一个编辑历史步骤。

`code` 是行内语义，`pre` 用于保留换行与空格的文本。避免为了视觉样式把所有内容转换为标题，或用连续空格模拟缩进。

已有 class、属性与 CMS 标记应保留；更改块类型后请检查 HTML 是否仍符合宿主样式要求。

## 常见错误

工具栏会根据选区启用或禁用命令。外部按钮应先恢复编辑器焦点，再执行公开命令；不要从 DOM 反向拼装正文。

## 颜色选择器（当前源码）

文字颜色、背景色和荧光笔共用取色面板：拖动色板调整饱和度与明度，使用色相／不透明度滑块，或输入 HEX、RGB(A)、HSL(A) 和 CSS 颜色名称。提供 HEXA、RGBA、HSVA 格式切换，默认 HEXA；保留预设色和最近使用的颜色，移除系统原生取色窗口，不需要额外的 Pickr 依赖。

拖动和输入只更新面板预览；点击“应用颜色”或在颜色值中按 Enter 才修改选中的正文，并产生一次撤销记录。“当前颜色”恢复打开面板时的颜色；取消、Escape 或点击外部放弃未应用的更改。清除按钮只移除对应的文字色、背景色或荧光笔。

色板支持方向键：左右调整饱和度，上下调整明度，Shift 加方向键大步调整；Home／End 调整到最低／最高饱和度。滑块支持原生键盘操作。颜色值错误时在输入框旁提示，并保留原有内容与选择。面板适配深色主题和窄屏，取色逻辑仍在第一次打开颜色菜单时加载。

以上为当前源码功能，尚未发布到公共版本；屏幕阅读器和真实移动设备的人工验收单独进行。
