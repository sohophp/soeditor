# 兼容与无障碍

站点支持键盘导航、搜索、代码复制和可见焦点。编辑器沿用其已发布版本的行为；本站浏览器自动化不代替真实设备验收。

上线前测试实际使用的 Chrome、Firefox、Safari、中文输入法、读屏工具以及 Word 粘贴来源。WebKit 自动化通过不等于真实 Safari 人工验收。

提供可辨识的 ariaLabel，并检查只读、对话框取消、焦点返回、缩放和窄屏表格。
