# 更新记录

## 1.4.0

视频工具默认开启，对话框与播放器按需加载，可用 `video: false` 关闭。修复图片调整宽高后上下添加段落工具的位置。React、Vue、视频及 SoFinder 搭配示例统一引用 npm 1.4.0。自托管全局脚本需保留完整 dist 目录。

## 1.3.0

新增 React、Vue CMS 组件入口，支持 HTML 绑定、表单提交与重置、SSR 和异步生命周期。修复 React 事件捕获期间的原生输入丢失。文档站同步到 npm 1.3.0，开放 React、Vue、视频示例，并推荐 SoFinder 为最佳资源管理搭档。

## 1.2.1

修复 1.2.0 默认 CMS ESM 初始化时的属性压缩问题。
