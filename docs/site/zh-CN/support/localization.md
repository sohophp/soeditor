# 多语言

通过 locale 选择编辑器语言。发布版提供英文、简体中文与繁体中文，宿主可通过 translations 提供自定义消息；direction 用于方向配置。

站点语言切换对应当前页面，示例同时切换宿主提示和编辑器语言。代码中的业务内容不自动翻译。

宿主自定义按钮、上传错误和保存状态也需要本地化，不能只翻译工具栏。
