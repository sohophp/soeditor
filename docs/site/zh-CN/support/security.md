# HTML 与安全

HTML 是规范保存格式。已有元素、属性、class、注释和 CMS 标记具有意义时应被保留。保留与可视化编辑能力、执行权限是不同概念。

编辑区域将脚本、事件处理器和不安全嵌入保持惰性。不能因此推断输出 HTML 在任意前台环境都可以安全执行；宿主应为最终呈现上下文执行服务端安全处理。

上传和保存端点需要宿主的身份验证、权限与请求保护。本站演示没有生产后端，也不收集编辑内容。
