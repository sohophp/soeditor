# Compatibility and accessibility

The site supports keyboard navigation, search, code copying and visible focus. The editor follows its published version’s behavior; site automation is not real-device qualification.

Test the Chrome, Firefox, Safari, IME, assistive technology and Word paste sources actually used by your authors. A passing WebKit test is not a manual Safari certification.

Provide a descriptive ariaLabel. Check readonly operation, dialog cancellation, focus return, zoom and narrow-screen tables.
