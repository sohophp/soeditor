# Links and CMS markers

Use the link dialog to read and edit the current link, supply its destination and confirm. Cancelling should preserve content and selection.

Comments, custom elements, classes and configured CMS placeholders can be meaningful content. Preservation does not permit execution: scripts, event attributes and executable embeds remain inert in the authoring surface.

Connect file links through the host asset picker. Persist canonical HTML, never temporary editor classes or selection state.
