# Source 格式化错误说明

手动格式化／压缩遇到 HTML 解析错误时，显示第一个错误的具体原因、解析器报告的行列（从 1 开始）和错误代码，并明确说明原文未变更。Worker 和 CSP 限制下的主线程回退使用相同诊断；错误信息以文字显示，不插入或执行输入的 HTML。

例如未关闭 `<style>`／`<script>` 会提示缺少结束标签；解析器可能在文末才发现这个问题，因此行列指向发现错误的位置，不一定是开始标签的位置。标签未完成、注释未关闭、重复属性和缺少属性值也有对应说明。

有效的 `<style>` 和内联 `style` 属性不因此被拒绝。HTML 格式化保留 CSS 原文，不格式化或校验 CSS 语法，也不会为了通过格式化检查自动删掉样式、修复标签或替换整个文章。失败不提交事务、不产生撤销记录。

错误提示支持英语、简中和繁中。未提供专门说明的解析器错误仍显示原始原因和稳定错误代码。源码未通过验证时，应先修复提示的问题，再重新格式化。
