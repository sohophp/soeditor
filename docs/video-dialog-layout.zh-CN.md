# 视频编辑窗口布局

视频运行时按需载入 `video-dialog.css`，窗口使用编辑器主题按钮、输入框和颜色。桌面宽度最多 44rem；视频和封面地址与选择按钮并排，宽度、宽高比、对齐方式并列。窄屏自动改为单列。

窗口高度限制在可视区域内，长内容在正文区域滚动，标题和确认、取消操作保持可见。“更多设置”保留原有折叠行为，字幕语言和名称并列，空状态提示不占空间。所有布局样式只作用于视频窗口。

`tests/browser/video.spec.ts` 覆盖 1280×800、390×700 窗口边界、输入框宽度和取消不修改内容，并保留视频插入、编辑、预览、文件选择及撤销检查。

视频预览的重新加载按钮和外部视频链接使用统一操作控件外观，保留链接的
新窗口打开语义。操作区采用主题颜色、统一间距、悬停与键盘焦点状态，窄屏允许
换行。样式随视频编辑窗口的播放器按需载入，不影响正文链接。


## 新窗口文章预览

文章预览直接渲染保存的 HTML，不再创建媒体覆盖层或注入重载、外链、状态提示。
原有 video 控件、iframe 地址和尺寸保留；编辑器内容更新时重新渲染文章。
视频编辑窗口内的独立预览仍提供重载操作。

文章 CSP 禁止脚本、事件属性、网络连接和表单提交，仅允许受信任的 YouTube
嵌入路径作为子框架。新窗口允许这些跨源播放器运行自身脚本，正文脚本仍受
`script-src 'none'` 限制。通用内嵌 Preview 引擎继续使用原有全禁脚本的 sandbox。
