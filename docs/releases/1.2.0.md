# SoEditor 1.2.0

Owner-authorized release preparation on 2026-09-08. Publication is performed only
from the clean, verified commit through the protected npm workflow.

## Scope

Optional native/YouTube video, safe article preview with demand loading and player
reuse, configurable toolbar drawers, keyboard selection correctness and table/image
paragraph insertion controls. See [changelog](../CHANGELOG.md),
[migration](../migration-1.1-to-1.2.md) and [configuration](../configuration.md).
The default CMS path keeps its existing loading budgets and Source stays lazy.

## Qualification

The former intermittent drawer keyboard failure is addressed by synchronously
capturing selection on focusout. A same-task selection/focus test covers the race;
twelve repeated runs passed for the combined drawer and dialog-cancellation
regressions. Empty transient ranges during native dialog focus restoration no
longer clear the saved authoring selection. CI follow-up also captures the engine
range on focusout and fixes current-value control widths so pressed toolbar buttons
cannot move during a format-state refresh. Focus/menu regressions passed 18 repeated
runs and WebKit anchor pointer-geometry checks passed 8 repeated runs.

Local qualification passed: lint, strict typecheck, the full `pnpm test`, 413 unit
tests, 162 Chromium product tests, 16 desktop/mobile CMS tests, 182 Firefox/WebKit
tests (4 existing skips), and 18 Source tests. Packed consumers, API/documentation
audits, loading/recovery budgets and the 24-package publish dry run passed. The
security audit found no known vulnerabilities.

The default global remains 484,272 bytes raw / 149,692 bytes gzip against the
unchanged 500,000 / 150,000 limits. In a 100-video production fixture, twelve
text edits retain the first player and cause no additional video request; scrolling
loads the next player. See [qualification evidence](../evidence/release-1.2.0.json). npm/CDN verification
runs after publication. The workflow result, commit SHA and immutable package
versions are the publication evidence; this document does not assert publication
before that evidence exists.

Real-device Safari, assistive technology and host-specific Office/IME checks retain
the documented qualification boundary. YouTube suggestions do not claim original
video dimensions, and network playback depends on provider availability.
