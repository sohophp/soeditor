# Changesets included in 1.1.0

These pending change descriptions are consumed by the aligned 1.1.0 release.

## flat-link-controls

Remove inherited field spacing so the added-attribute selector and removal
button share an exact visual baseline.

## neat-links-focus

Align the additional-link-attribute removal control with its selector and keep
focus on the selector while loading an attribute for editing.

## calm-shadows-edit

Fix WYSIWYG Shadow DOM selection, link range restoration, paragraph-boundary
deletion, word counts, and rich paste interoperability in Firefox and WebKit.

## fresh-links-smile

Add validated custom attributes to the link editor, including tag-specific
suggestions, enumerated values, CMS attribute round trips, and responsive UI.

## clean-format-blocks

Keep paragraph, heading, and other block structure intact when clearing inline
formatting across a multi-block selection, and paragraphize legacy root-level
inline content when a block command is explicitly chosen.

## bright-cms-boundaries

Add bounded side-by-side and stacked WYSIWYG/Source views, debounced Source
formatting, passive selection synchronization, and isolated popup preview
templates while keeping Source, Preview, their styles, and host-owned file
management outside the default CMS runtime. Source, Preview, and save adapters
now use the explicit `@soeditor/editor/cms/optional` entry. Integrations that
need the bundled file-manager/upload commands can pass `cmsPreset` explicitly.
Historical Classic, Developer, and Markdown preset controls now register through
the explicit `@soeditor/ui/compatibility` entry, so those supported presets keep
their documented toolbar behavior without adding Preview, Media, or Markdown UI
to the default CMS bundle.

## valid-block-content

Prevent block-format commands from creating invalid nested flow content such as
`<p><p>…</p></p>`, while preserving block order, attributes, and PRE line breaks.
Ignore temporary selection markers when deciding whether surrounding whitespace
requires a paragraph.

## wise-tables-grow

Add a transaction-backed table structure API and ClassicEditor panel for
captions, multiple table sections, safe column groups, semantic row and column
headers, bounded table insertion, last-cell Tab row creation, responsive table
styles, and single-commit column resizing.

## steady-pre-breaks

Serialize line breaks as canonical `<br />` tags; keep Enter, Shift+Enter, and
plain-text insertion inside `pre` as literal newline text; and convert between
newline text and `br` elements when switching `pre` and `p`/`div` blocks. Block
commands now paragraphize selected legacy root-level inline content on demand.

## quiet-links-check

Reject unsupported link attribute names and refine the compact additional
attribute editing layout, localized validation, and edit/remove workflow.

## Final publication verification fixes

- Registry verification now accepts stable semantic versions beyond 1.0.x.
- Browser tests resolve module paths from the checkout and wait for native menu initialization before measuring placement.
- The color menu preserves input received before its queued native toggle event. A deterministic regression fails against the previous implementation (the entered `#123456` becomes `rgb(0, 0, 0)`) and passes with the fix; color and menu keyboard checks passed 10 repeated runs.
- The final color fix builds at 480.77 kB raw / 148.48 kB gzip for the CMS global, with unchanged 24.93 kB stylesheet and unchanged budgets. GitHub CI and the publishing workflow provide the final commit-level validation.
