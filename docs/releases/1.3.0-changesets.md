# 1.3.0 version alignment

The React and Vue CMS entry points are additive public APIs and require a minor release. All 24 public package manifests and the private workspace manifest advance from 1.2.1 to 1.3.0 together. Existing package-root compatibility APIs remain unchanged.

Applied changeset:

```md
---
'@soeditor/react': minor
'@soeditor/vue': minor
'@soeditor/wysiwyg': patch
---

Add separate React and Vue CMS components and preserve native input during React event capture. Align the complete public package set at 1.3.0.
```
