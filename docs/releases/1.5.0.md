# SoEditor 1.5.0

Owner-authorized on 2026-10-07. All 24 public packages align at 1.5.0.

## Changes

- Opt-in rich paste choices: preserve, semantic cleanup or plain text. Cancellation, stale operations, readonly, composition and destruction preserve content safety. See [paste details](../paste-choice.zh-CN.md).
- Localized Source formatting diagnostics report the first reason, line, column and error code without modifying invalid HTML. See [formatting details](../source-formatting-errors.zh-CN.md).
- Accumulated CMS fixes cover link search, image properties and content-base previews, safe element unwrapping, disclosure lifecycle, source-preserving formatting and external-paste alignment.
- Optional Classic Chinese resources and canvas presets load only when requested; formatting feedback and its compact inline worker remain behind first-use boundaries. WebKit toolbar selection stays frozen across asynchronous tool imports.
- ESM toolbar link, color, image and table panels load on first activation. CMS presets stay inside the mounted runtime boundary; global translations and link tools use separate lazy companions. Self-host the complete dist directory.

## Toolchain security
