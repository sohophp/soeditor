# SoEditor 1.5.0

Owner-authorized on 2026-10-07. All 24 public packages align at 1.5.0.

## Changes

- Opt-in rich paste choices: preserve, semantic cleanup or plain text. Cancellation, stale operations, readonly, composition and destruction preserve content safety. See [paste details](../paste-choice.zh-CN.md).
- Localized Source formatting diagnostics report the first reason, line, column and error code without modifying invalid HTML. See [formatting details](../source-formatting-errors.zh-CN.md).
- Accumulated CMS fixes cover link search, image properties and content-base previews, safe element unwrapping, disclosure lifecycle, source-preserving formatting and external-paste alignment.
- Global translations and link tools use separate lazy companions, retaining the existing startup budgets. Self-host the complete dist directory.

## Toolchain security

See [dependency updates and the tested braces depth mitigation](../security-toolchain-2026-10-07.md). The release audit still rejects other high/critical advisories.

## Verification

- Local lint, workspace type checks, 429 unit tests, API compatibility report and documentation audit passed.
- Integration performance budgets passed, including 0.22 MiB retained memory after collection.
- Global main script: 484,700 bytes raw / approximately 149,040 gzip; standalone main CSS: approximately 25,950 bytes. Existing 500,000 / 150,000 / 27,000-byte limits remain unchanged.
- Security gate passed after dependency updates and eight installed-patch regression tests. One moderate development-tool advisory remains; the mitigated braces advisory is documented separately.
- Packed consumers, release packaging, Chromium, loading measurements and remote cross-browser gates continue before publication.
  Real-device Safari, operating-system IME, Office versions and assistive-technology
  qualification remain separate from automated browser checks.
