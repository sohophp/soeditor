# SoEditor 1.4.0

The owner requested default video tools, a new release and synchronized documentation on 2026-09-09. All 24 public packages align at 1.4.0.

## Changes

- Default Classic video controls and inert cards, with `video: false` opt-out and configurable origin policy. Custom toolbars remain explicit; existing video plugins take precedence.
- Dialogs and players load only on demand; default metadata lookup is disabled. CDN/global image tools now use a companion asset to retain the existing 500/150 kB raw/gzip startup limits. Self-host the complete `dist` directory.
- Image paragraph tools follow the actual image after resizing and when switching images within one text block; paragraph insertion still preserves the complete block and undo behavior.

See [image positioning evidence](../image-type-around-position.zh-CN.md). Local checks, protected publication and online documentation verification are recorded separately.

## Local validation

- Build, lint and typecheck passed. Unit, performance, API, documentation, packed consumers, distribution and release checks passed; 170 product browser and 16 desktop/mobile CMS cases passed. The final media/CDN follow-up passed all 23 cases.
- Focused Chromium tests cover default/disabled video, failed-import retry, global CDN insertion/re-editing and inert cards, plus inline-image resize/type-around/undo.
- Loading measurement passed for 10/100/500 KiB documents, first/repeated Source, formatting, teardown and recovery. Global JS: 482,635 raw / 149,745 gzip bytes. Optional startup: 521,888 / 155,379 bytes. See [the measured startup decision](../decisions/0081-default-classic-video.md).
- Pinned the documentation preview toolchain's `miniflare>sharp` to 0.35.4 for [GHSA-rgj7-g3m4-5g8c](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c). High-severity audit gate passes; two existing moderate Vitest development-tool advisories remain.

- CDN companion URLs are checked against a main script in a different directory from the host page. The video runtime URL is captured while the main script executes, before `document.currentScript` becomes unavailable.

- Final Firefox/WebKit container regression: 186 passed, 4 skipped. Keep image paragraph tools when resize returns focus to the surface; reserve the browser `shadowRoots` option during global property minification so WebKit can recover the editing caret.

- Additional local Playwright Noble checks: Source 27/27 and React/Vue framework flows 21/21 passed across Chromium, Firefox and WebKit. The host lacks Firefox/WebKit libraries, so these checks used the existing isolated browser container.

## Publication and documentation

- All 24 public packages were published as 1.4.0 from `ff77a45570e47f4e4cac6f8a9fa779ea1ada54fa`; [protected publication and registry verification](https://github.com/sohophp/soeditor/actions/runs/34304868706) passed after repository CI.
- Documentation now imports exact published 1.4.0 packages, including React/Vue examples and the downloadable project. Documentation checks/build passed (43 pages per locale, 5,794 links); desktop/mobile browser checks passed 55 cases with one skipped. The downloaded example project installs and builds successfully.
- Cross-origin CDN scripts require `crossorigin="anonymous"` and a CORS-enabled server to resolve lazy image tools. Both language guides include this requirement; self-hosted installations must retain the complete `dist` directory.
- Live jsDelivr 1.4.0 verification passed with the documented CORS setting: lazy video dialog, canonical insertion, lazy image tools, image resize and teardown.
