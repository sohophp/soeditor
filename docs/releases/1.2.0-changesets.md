# Changesets included in 1.2.0

## article-video-preview

```markdown
---
'@soeditor/preview': minor
'@soeditor/editor': patch
---

Support optional validated YouTube players in Classic whole-article preview while
keeping authored scripts and unknown embeds inert. Add the explicit preview/media
service entry and dispose player layout observers on refresh and teardown.

Load preview players on viewport entry, retain unchanged YouTube/native players
and scroll through text edits and template changes, and share recovery controls
with the properties preview. Collapse native advanced settings and qualify
multi-video, disclosure, narrow, zoom, wheel and keyboard workflows.
```

## configurable-toolbar-drawers

```markdown
---
'@soeditor/ui': minor
'@soeditor/editor': minor
'@soeditor/presets': minor
---

Show strike, subscript, superscript and remove-format as individual CMS toolbar icons by default. Support labeled toolbar drawer groups containing registered command/dialog buttons, while retaining the fixed moreFormatting drawer for compatibility.
```

## optional-cms-video

```markdown
---
'@soeditor/editor': minor
'@soeditor/wysiwyg': minor
'@soeditor/ui': patch
---

Add an explicitly imported Classic video plugin with lazy properties and preview,
inert native/YouTube cards, asset picker support, canonical HTML and atomic history.
Expose an instance-owned atomic projection hook and preserve canonical element paths.
Load Classic dialog move/resize controls on first dialog use and share toolbar
drawer mounting to retain the existing initial bundle budgets.
Autofill untouched YouTube title and card cover fields after URL input, with
cancelable metadata requests, manual-edit protection and an explicit opt-out.
Keep YouTube previews visible at usable landscape/portrait sizes and provide
loading feedback, reload and a watch link when the embedded player fails.
```

## table-paragraph-position

```markdown
---
'@soeditor/editor': patch
---

Place table paragraph controls above and below the table instead of outside the left and right edges. Avoid covering captions or cells. Keep shared image/table controls aligned when the editor host is zoomed, split, or scrolled.

Keep the pointer corridor between the table and its paragraph buttons active, including the transparent corners of circular buttons, so authors can move to and click either control.
```
