# SoEditor 1.3.0

The owner authorized publication of the React/Vue CMS improvements and the updated documentation site on 2026-09-09.

## Changes

- Separate React and Vue CMS components with HTML binding, form submit/reset, readonly updates, lifecycle callbacks, SSR rendering and asynchronous cleanup.
- React capture-phase native input no longer loses typed content; cancelled beforeinput still allows external DOM repair.
- Existing Workspace hooks remain supported. Framework runtimes stay outside the default CMS entry; Source remains optional and lazy.
- Bilingual React, Vue and video guides and examples, with SoFinder highlighted as the recommended asset management companion.

All 24 public packages align at 1.3.0. This is an additive minor release without public API removals or increased bundle budgets.
