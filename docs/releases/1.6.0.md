# SoEditor 1.6.0

Owner-authorized release candidate on 2026-10-24. All 24 public packages align at 1.6.0. Publication, public registry/CDN verification and documentation deployment remain pending.

## Changes

- Compact inline spectrum with hue and opacity sliders for text, background and highlight colors; no native system color dialog or additional runtime dependency.
- Default HEXA display, RGBA and HSVA format switching, current/preset/recent colors and localized keyboard interaction.
- Apply commits one undo step; Cancel/Escape/outside clicks preserve content and selection. Unformatted transparent backgrounds start a fully opaque draft; existing semitransparent colors retain their alpha.
- Hue changes reveal a visible color from black/gray; HSV state is retained without RGB round-trip drift.
- Lazy global JavaScript and detailed styles remain independent companions. Self-host the complete `dist` directory, including `classic-color-tools.js` and `classic-dialogs.css`.

## Toolchain security

Update Vite to 7.3.7 (VitePress nested Vite 6.4.4) and undici to 7.30.1 to resolve the current high-severity advisories. The checked braces mitigation and existing security gate remain enabled.

## Verification

- Local lint, workspace type checks, 456 unit tests, integration performance budgets, public API and documentation audits passed.
- Packed NodeNext/ESM, CMS Source/formatting/recovery, third-party widget, narrow Vite and plugin scaffold consumers passed. Existing total/chunk budgets remain unchanged.
- The product Chromium run passed 209 cases; the remaining old RGB expectation was updated to the new default HEXA and its targeted retry passed. All 16 desktop/mobile CMS cases and 14 focused desktop/touch color cases passed.
- Global main script: 483,747 bytes raw / 148,589 gzip; main CSS 26,413 bytes. The 500,000 / 150,000 / 27,000-byte limits remain unchanged.
- Security audit passed with no high/critical advisories; two moderate development-tool advisories remain.
- Public API entry points remain compatible. Automated browser evidence does not replace real-device Safari, operating-system IME or assistive-technology qualification.

Winstar's built color/language integration passed seven cases. Its broader integration run had failures in older chrome/media/asset expectations and was stopped; this release does not claim the entire Winstar suite passed.
