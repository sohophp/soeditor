## Changes

- Compact inline spectrum with hue and opacity sliders for text, background and highlight colors; no native system color dialog or additional runtime dependency.
- Default HEXA display, RGBA and HSVA format switching, current/preset/recent colors and localized keyboard interaction.
- Apply commits one undo step; Cancel/Escape/outside clicks preserve content and selection. Unformatted transparent backgrounds start a fully opaque draft; existing semitransparent colors retain their alpha.
- Hue changes reveal a visible color from black/gray; HSV state is retained without RGB round-trip drift.
- Lazy global JavaScript and detailed styles remain independent companions. Self-host the complete `dist` directory, including `classic-color-tools.js` and `classic-dialogs.css`.
