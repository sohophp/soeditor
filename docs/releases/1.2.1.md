# SoEditor 1.2.1

The owner requested a patch release before deploying the public documentation site.

## Fix

The published 1.2.0 CMS ESM artifact preserved quoted parse5 enum definitions but
mangled property reads with `keep_quoted: 'strict'`. The tokenizer could enter an
undefined state and loop during initial HTML parsing. Correcting quoted keys also
exposed inconsistent internal property names across independently minified ESM
chunks. Disable property mangling for the split ESM build; retain ordinary
identifier minification and the existing self-contained global build strategy.

The new browser regression imports the actual built CMS ESM entry and checks
initial HTML, comments, CMS attributes, table cells, replacement and teardown.
Public APIs and distribution budgets are unchanged. All 24 packages align at 1.2.1.

## Verification

Local verification on Node 22.14.0 and the Playwright 1.62.1 Noble container:

- `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build` passed.
- The full test command includes 163 product browser cases and 16 Chromium/mobile CMS cases.
- Built-distribution browser regression suite: 5 passed.
- `pnpm test:loading` passed without increasing budgets.
- Global artifact: 484,292 raw bytes / 149,705 gzip bytes.
- All 24 package licenses passed; registry preflight found 1.2.1 unpublished.

The registry verifier now waits for the requested version in npm install indexes,
because a successful HTTP response can still contain stale metadata immediately
after publishing. Remote publication evidence is recorded separately; these local
results do not assert npm publication.
