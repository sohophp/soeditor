# CMS 表格与列表

CMS 预设把表格作为原子结构块编辑。所有结构与属性修改都通过命令和单次事务写回规范 HTML；投影 DOM 不是数据源。后端 HTML 不需要包含任何 `soeditor-*` class；这些类仅用于编辑器投影交互，序列化时不会写入 `getData()`，因此同一份内容可以在不同后台和宿主样式中复用。

## 表格编辑服务

`@soeditor/rich-text` 公开 `TableEditorService` 与 `tableEditorServiceToken`。集成方可通过 `inspect()` 获取当前表格、显式分区、行、单元格、选择范围、可编辑状态和中文诊断，并使用以下接口修改内容：

- `updateTable()`、`updateSection()`、`updateRows()`、`updateCells()`；
- `executeStructuralAction()`，统一执行增删行列、表头切换、合并、拆分、清空和删除；
- `recover()`，只为可安全恢复的零行表格添加首行首列。
- `inspectStructure()` 返回 caption、全部显式分区、多个 colgroup 及稳定诊断；
- `updateCaption()`、`createSection()`、`removeSection()`、`moveRows()`、`reorderBodySection()` 管理结构且不隐式改写单元格语义；
- `createColumnGroup()`、`updateColumnGroup()`、`removeColumnGroup()` 只修改可证明安全的列组，复杂历史结构保持只读；
- `repairStructure()` 仅执行诊断中明确标记为可修复、并经用户确认的动作。

旧表格命令继续可用。ClassicEditor 将普通作者界面收敛为 CKEditor 4 风格的“表格属性”和独立“表格标题”：属性对话框处理尺寸、对齐、边框、单元格间距与内边距、摘要和无障碍字段；caption 未提交修改时保留原有行内结构，提交新文字时保留元素属性并以纯文本替换内容。行列增删、选择、合并、拆分和表头切换位于表格上下文工具中；thead/tbody/tfoot 与 colgroup 的高级结构命令继续保留给集成 API 和源码工作流，不占用普通作者对话框。

`table.column.resize` 支持 40–1200px 数字输入、键盘调整与投影层拖拽。拖拽只在结束时提交一次事务，Escape 取消；外部复杂 colgroup 无法安全映射时不会显示拖拽柄。响应式 class 仍由宿主配置，投影层默认水平滚动，并提供 `soeditor-table--sticky-header` 与 `soeditor-table--sticky-first-column` 可选样式。

## Dreamweaver 式选择与上下文界面

表格由投影层维护唯一结构选择。普通单击编辑文字，Shift 单击扩展矩形，按住主鼠标键从一个单元格拖到另一个单元格也会形成矩形选择。上下文工具提供“选择当前行”“选择当前列”“选择整表”，右键菜单调用同一组 `table.selection.*` 命令。选择范围、蓝色高亮、命令参数和按钮状态不再由不同 UI 各自推断。

工具栏按选择层级精简：

- 光标：单元格、分区、行列插入、表头和删除操作；不显示不可用的合并；
- 单元格矩形：合并、清空和批量单元格属性；
- 行或列：只显示对应方向的插入、删除、属性和适用的批量操作；
- 整表：只显示整表属性、清空和删除等表格级操作。

属性按钮直接打开当前选择层级，不再经过四层中转对话框。表格、显式分区、行和单元格附加属性能力继续保留。

`TableEditorSnapshot` 同时公开 `selectionKind` 与 `capabilities`。能力包含可用状态及中文原因，第三方界面不需要通过 CSS 类猜测是否可以合并或拆分。

宽高统一使用“整数＋单位”，允许 `1–9999px` 或 `1–100%`；清空即删除属性。像素值写为原生整数属性（如 `width="320"`），百分比保留 `%`。表格和单元格尺寸、对齐、class 以及简单列组都使用标准 HTML 属性；列拖动只修改简单 `colgroup` 中对应的 `<col width="…">`，复杂或无法安全映射的外部列组保持不变。

附加属性按 `table`、分区、`tr`、`td`、`th` 分别列出。事件属性、内部 `data-soeditor-*`、危险属性、重复的专用属性和不适用于当前标签的属性会在界面与命令层同时拒绝。已有废弃属性不会被主动删除，但界面不推荐新增。

`rowspan` 与 `colspan` 不能在属性页直接修改；合并和拆分命令是唯一结构入口。

合并只接受同一显式分区内连续的直线或矩形选择；不能跨 `thead`、`tbody`、`tfoot`，也不能包含现有跨度冲突。拆分提供 `table.cell.splitRows`、`table.cell.splitColumns` 和兼容的完全拆分 `table.cell.split`。新建的拆分单元格不会复制源单元格的 `id`。

行列插入命令保持无参数调用兼容，同时接受 `{ count: 1..100 }`。ClassicEditor 选择多行或多列后执行对应插入，会在单个事务中按选择数量创建新行或新列。

插入按钮提供键盘可操作的 10×10 网格和精确行列输入，打开时默认选择 3×3；`table.insert` 公共命令同样允许集成方提供精确尺寸，最多 100 行、100 列且总计不超过 1,000 个单元格。最后一个单元格按 Tab 会新增一行，Shift+Tab 仍向前移动；Shift+方向键扩展矩形结构选择。

`table.header.firstRow` 将首行转换为 `th scope="col"`，`table.header.firstColumn` 将首列转换为 `th scope="row"`；复杂合并标题不会被自动推断为 rowgroup 或 colgroup。

## 异常与恢复

零行表格不再把内部解析异常显示给用户。仅包含标题、列组、空分区或空白内容的零行表格可安全添加首行首列，并可通过编辑器历史撤销。结构诊断还可在确认后移除无属性、无内容的重复空分区，但不会删除最后一个有效 tbody。

非矩形、跨度冲突、嵌套表格或含不支持子节点的表格保持原 HTML 不变，投影为诊断占位界面，只提供源码修复和删除。上下文结构命令不会在异常状态下反复执行同一失败操作。

## 单元格内容与剪贴板

单元格仍支持普通富文本编辑、键盘移动、矩形选择、复制粘贴和单元格 HTML 编辑。嵌套表格不受支持。表格矩阵粘贴限制为 100 行、100 列、1,000 个单元格及 1,000,000 个输入字符，并经过粘贴管线和安全过滤；当前目标空间不足或与跨度单元格冲突时整次拒绝，不会截断或留下半完成修改。外部 Word、Excel、LibreOffice 和网页表格的安全 caption、分区、colgroup、跨度及 scope 语义由 CMS 粘贴清理保留。

列表继续使用受控段落元数据，保留有界层级、起始序号和标记属性；不支持的列表结构保持不透明，不会被静默扁平化。
