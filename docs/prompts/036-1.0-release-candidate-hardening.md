# Phase 36 — SoEditor 1.0 Release Candidate and Hardening

## Status

COMPLETE.

## Goal

Produce one coherent, owner-reviewable SoEditor 1.0 release candidate from the
frozen and qualified public API.

## Required implementation

1. Align all 23 public package manifests, internal dependency ranges, consumer
   fixtures, release checks, changelog, and versioned documentation at 1.0.0.
2. Verify licenses, export maps, declarations, maps, CSS, ESM/global builds,
   framework packages, packed consumers, and provenance metadata.
3. Run the complete lint, type, unit, API, documentation, performance,
   browser, accessibility, security, dependency, bundle, lifecycle, consumer,
   distribution, release, dry-run, and registry gates.
4. Perform a final adversarial review and document every accepted Medium/Low
   limitation without weakening the frozen stable API contract.

## Explicitly deferred

- npm publication, Git tags, GitHub Releases, and external CDN verification
  until the repository owner explicitly authorizes those external actions;
- new editor features, architecture rewrites, or unsupported compatibility and
  certification claims.
