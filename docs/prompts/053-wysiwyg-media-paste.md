# Phase 53 — WYSIWYG Assets, Media, Upload, and Paste

Complete CMS asset and external-content authoring in the independent WYSIWYG
surface.

## Contract

- Present one image action with computer upload, replaceable file manager, and
  URL insertion paths.
- Keep transport and asset selection host-owned behind typed services.
- Support upload progress, cancellation, retry, validation, temporary-preview
  cleanup, and a canonical save boundary.
- Image double-click opens complete properties and restores the native range.
- Media is visibly selectable/editable while playback and arbitrary execution
  remain isolated from authoring.
- Classify internal, web, plain, Office, Google Docs, and LibreOffice paste;
  apply configured semantic, keep-formatting, plain-text, and image policies.
- Rich cell paste uses the same pipeline as ordinary content and creates one
  undo step.

No bundled storage backend, proprietary manager, transcoder, or arbitrary
executable embed is authorized.
