# Phase 33 — SoEditor 0.9 Integration Release

## Status

COMPLETE.

## Goal

Promote the validated application-integration layer and harden the complete
SoEditor 0.9 package line without performing an owner-controlled publication.

## Required implementation

1. Align all public packages at `0.9.0` and promote Workspace, React, Vue, and
   plugin tooling through documented package-root exports.
2. Add packed NodeNext, browser/framework, CMS, SSR-import, and CLI consumers
   for the promoted surfaces.
3. Add a reproducible large-document performance gate covering input,
   projection, annotations, tables, startup, teardown, and recovery, while
   retaining existing bundle budgets.
4. Document 0.8-to-0.9 migration, framework/CMS integration, public API and
   dependency boundaries, and the exact owner-controlled release procedure.
5. Run lint, strict typecheck, unit, consumer, distribution, release, browser,
   accessibility, security, license, npm dry-run, registry preflight, and
   adversarial reviews.

## Explicitly deferred

- actual npm publication, git tag, hosted release, or CDN verification without
  separate owner authorization;
- 1.0 API freezing, support/deprecation policy, or compatibility promise;
- Angular/Svelte adapters, hosted plugin marketplace, telemetry, remote code
  loading, and real-time collaboration.
