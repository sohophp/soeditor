# 图片缩放后的段落工具定位

1.3.0 的图片与文字处于同一个标题或段落时，段落工具错误地使用整块文本的边界定位。图片调整宽高后，按钮仍可能出现在远离图片的位置。同一文本块中的多张图片也会复用此前的定位目标。

修复将图片边界与段落插入边界分开：按钮始终跟随当前图片，段落仍插入在完整文本块前后。带图注的 figure 继续把图注包含在下方边界内。尺寸变化沿用现有 MutationObserver / ResizeObserver 更新，不增加常驻监听器或默认加载内容。

回归覆盖含文字和两张图片的标题、键盘调整宽高、鼠标拖动缩放、图片之间切换、完整标题后的段落插入和撤销。修复前，回归检测到工具与图片左边界相差 77px、宽度相差 675px；修复后要求工具矩形与图片矩形各维度的舍入差均为 0。

此记录描述仓库修复；npm 和文档站仍需后续补丁发布才能获得更新。

## 验证

- 定向图片缩放、图片定位、图片对齐与表格段落工具：4 项 Chromium 测试通过。
- `pnpm lint`、`pnpm typecheck`、`pnpm test` 通过；完整测试包含 169 项产品浏览器测试和 16 项桌面／移动 CMS 流程测试。
- 按需工具的压缩模块由 4,320 / 1,703 字节（raw / gzip）降至 4,283 / 1,687 字节。打包 CMS 消费者为 494,969 / 149,535 字节，仍在原有预算内。
- 本轮浏览器验证为 Chromium；未重新验证 Firefox、WebKit 或人工 Safari。
