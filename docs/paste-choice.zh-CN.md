# 富文本粘贴选择

Classic 可通过 `config: { cms: { paste: { prompt: true } } }` 启用每次外部富文本粘贴的选择框。默认关闭，以保持已有宿主的自动粘贴行为；Winstar 已启用。

- 网页 HTML、Word／Excel、Google Docs、LibreOffice 内容会显示识别来源。
- 剪贴板仅有文字但看起来是 HTML 源码时，也询问处理方式。只有明确选择保留／清理格式才将源码解释为 HTML；仅保留文字将代码作为文字插入。
- 普通文字、编辑器内部复制和文件粘贴保持原流程；拖放继续使用宿主配置，不弹出此对话框。
- 保留格式：保留可用的结构、样式、class 等，但仍过滤危险脚本、事件属性和不安全网址。
- 清理格式：使用现有 semantic 策略及宿主的 `retainStyles`、`retainAlignment` 设置。
- 仅保留文字：使用剪贴板纯文本表示，不插入 HTML。
- 取消或 Escape 不写入正文，不创建历史记录；确认仍使用原有插入事务，支持一次撤销／重做。
- 三种方式纵向排列为可点击卡片，每个选项紧跟自己的说明，点击即应用；底部只保留取消。卡片支持 Tab、Enter／Space 和独立的辅助技术说明；HTML 源码的纯文字选项明确说明不会解析标签。

浏览器复制网页不保证包含完整页面 CSS，也不是原始 HTML 的逐字复制。此功能不导入网页 head 或外部样式表，不承诺完整复刻设计页。需要完整 body 代码时可使用 HTML Source。

选择只作用于本次操作，不改变宿主默认策略。`PastePipelineInput.policy` 提供有类型的单次策略覆盖；内部复制仍强制 preserve。无 DOM 的 `pasteDecisionServiceToken` 提供可替换的异步 UI 边界，取消返回 `undefined`，实例失效使用 AbortSignal。不得在此 UI 中预览／执行剪贴板 HTML。

对话框按需加载；打开前不解析整篇文章。原有输入／输出长度限制保持不变，超限会整次拒绝并提示，不截断内容。等待选择期间的正文替换、readonly、模式切换、后续粘贴或销毁使旧操作失效；中文组合输入期间不执行结构粘贴。多个实例不共享选择或剪贴板数据。
