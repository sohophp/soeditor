# @soeditor/vue

Public 0.9 Vue Composition API lifecycle adapter for
`@soeditor/workspace`.

`useSoEditorWorkspace()` mounts in `onMounted()`, cleans up in `onUnmounted()`,
and watches controlled value and readonly refs without rebuilding the Editor.

See [`docs/framework-adapters.md`](../../docs/framework-adapters.md).
